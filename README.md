# Нейросетевой репетитор
Мобильное приложение, которое автоматически генерирует тесты на основе ваших конспектов и учебных материалов.

## О проекте 

Нейросетевой репетитор помогает студентам и преподавателям быстро создавать проверочные тесты для самопроверки и контроля знаний. Достаточно сфотографировать страницу конспекта или вставить текст вручную - и приложение само составит вопросы на различные темы.

Нейросеть генерирует тест с вопросами и вариантами ответов. Пользователь проходит тест, получает результат и сохраняет его в историю для повторения.

## Технологии
- Kotlin
- MVVM
- Работа с Room
- DI: Hilt
- UI: Compose
- Работа с сетью: Retrofit, OkHttp
- Kotlin Coroutines, Flow
- Jetpack Navigation Component
